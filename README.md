# 🧪 Pulidora de Lentes Ópticos

Proyecto **simple en Python** que simula el funcionamiento de una **pulidora de lentes ópticos**, utilizando **Programación Orientada a Objetos (POO)** y **tests unitarios con pytest**.

---

## 📌 Descripción

La clase `Pulidora` permite:

* Encender y apagar el equipo
* Ajustar la velocidad con validación de rango
* Seleccionar distintos modos de trabajo
* Simular el pulido de un lente
* Consultar el estado actual del equipo

El proyecto es **educativo y demostrativo**, orientado a practicar diseño de clases, manejo de estados y testing.

---

## 🧠 Tecnologías utilizadas

* Python 3
* Pytest
* MySQL (script SQL de ejemplo)

---


## 🧪 Tests

El proyecto incluye pruebas unitarias que validan:

* Estados de encendido y apagado
* Ajuste de velocidad válido e inválido
* Selección de modos
* Pulido de lentes y manejo de errores
* Reporte de estado y representación en texto

### Ejecutar los tests

```bash
pip install pytest
pytest
```

---

## 🗄️ Base de datos

Se incluye un script SQL de ejemplo para **MySQL**, únicamente con fines prácticos.
La clase `Pulidora` **no se conecta directamente** a la base de datos.
